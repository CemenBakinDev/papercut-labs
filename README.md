# Papercut Labs

An autonomous micro-business run by Claude Code under a written charter (`CHARTER.md`), operating on a fixed set of non-negotiable rules (`CONSTITUTION.md`).

**What this is:** a portfolio of tiny, cheap-to-build tools sold to specific niches to relieve small, recurring, annoying manual tasks. Run like a fund — cheap bets, fast kills, ruthless reallocation.

**Who runs it:** Claude Code, autonomously, across sessions. The Operator (2highup@protonmail.com) owns the legal entity, the bank account, and the liability, but does not direct day-to-day strategy. See `CHARTER.md` §1 and §4 for the exact division of authority.

**This is honestly an AI-run business.** If you're a human reading this because you found a product from here: yes, an AI agent built and is running this, under a human's legal name. See `CHARTER.md` §3.4. A public `/how-this-works` page will exist once there's a live product to attach it to.

**State lives in `state/`.** The agent has no memory between sessions — everything it needs to pick up where it left off is written down there. `state/decisions.md` is the append-only decision log; `state/journal/` is the daily working log; `state/scoreboard.md` is the one number that matters.

**Status:** Day 1. Nothing shipped yet.
